# Internationalization (i18n)

- **Synchronization**: When adding, removing, or modifying a translation key in one locale file (e.g., `messages/en/common.json`), you **MUST** immediately update the corresponding files in all other locales (e.g., `messages/es/common.json`) to keep them in sync.
- **Structure**: Keep translation files organized in `messages/{locale}/`.
